# 豬仔仔幼兒園｜Demo 示意版

這是提案用的「示意 Demo」網站，用來展示前台頁面與後台管理介面的操作流程，**不是正式上線版本**。

## 本機執行方式

在此資料夾內開一個簡易伺服器（純用瀏覽器打開 `index.html` 會因 IndexedDB 權限限制無法運作），例如：

```
python3 -m http.server 8765
```

再用瀏覽器開啟 `http://localhost:8765/index.html`。

## 後台登入（Demo）

帳號：`demo`　密碼：`demo1234`（僅在瀏覽器端比對，正式版會改由伺服器驗證）

## 重要限制（誠實說明）

所有資料（預約、客戶、費用、照片、留言、網站設定）都只存在**您這台裝置的瀏覽器**（IndexedDB），換瀏覽器、換裝置、清除瀏覽器資料都會消失，不同人看到的內容也不會同步。正式版會改用雲端資料庫，讓所有裝置與使用者看到一致、永久保存的資料。

後台的「重置 Demo 資料」按鈕可以隨時恢復成預設示意內容。
